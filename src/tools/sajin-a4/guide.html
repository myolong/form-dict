이렇게 쓰세요

  1. 사진 고르기 — 영수증이나 사진을 한꺼번에 여러 장 고릅니다. 휴대폰에서는 사진 보관함에서 바로 고를 수 있어요.
  2. 칸 수 정하기 — 한 장에 넣을 개수를 고르면 A4에 자동으로 배치됩니다. 사진이 많으면 여러 장으로 이어져요.
  3. 순서·회전·설명 — 왼쪽 목록에서 ↑↓로 순서를 바꾸고, ⟳로 돌리고, 사진마다 설명(예: 11/3 택시비 12,800원)을 적습니다.
  4. 인쇄·PDF — [인쇄 · PDF 저장]을 누르고 인쇄 창에서 프린터나 'PDF로 저장'을 고릅니다.

이럴 때 쓰면 좋아요

  • 지출결의서·출장비 정산에 붙일 영수증 모으기
  • 공사·현장 사진, 하자 사진을 날짜별로 정리해 보고하기
  • 중고거래·택배 파손 증빙 사진 모아 두기
  • 아이 작품·여행 사진을 한 장에 모아 인쇄하기

잘 나오게 하는 팁

  • 영수증은 밝은 곳에서 위에서 똑바로 찍으면 글씨가 잘 보여요.
  • 설명 칸에 날짜·금액을 적어 두면 지출결의서에 옮겨 적기 편합니다.
