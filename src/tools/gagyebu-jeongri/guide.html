  1. 내역 파일 받기 — 카드사나 은행 홈페이지·앱에서 이용내역(거래내역)을 조회한 뒤 '엑셀 다운로드'로 저장합니다. 한 달 단위로 받으면 보기 편해요.
  2. 파일 넣기 — 위 칸에 끌어다 놓거나 눌러서 고릅니다.
  3. 열 확인 — 날짜·사용처·금액 열을 자동으로 골라 두니 미리보기 표에서 맞는지만 확인합니다. 통장 내역은 '통장(출금·입금 따로)'을 고르세요.
  4. 분류 고치기 — 자동 분류가 틀린 거래만 바꿉니다. 같은 가게는 한 번만 바꾸면 됩니다.
  5. 인쇄·저장 — A4 가계부로 인쇄하거나 PDF로 저장하고, 엑셀로 저장해 두면 다음 달 파일과 이어 붙여 볼 수 있어요.

분류 기준

가게 이름에 들어간 단어로 나눕니다. 예를 들어 '커피·카페·베이커리'는 카페·간식, '마트·정육'은 장보기, '택시·주유·주차'는 교통·차량, '관리비·전기·가스'는 주거·공과금으로 들어갑니다. 이름만으로 알 수 없는 가게는 기타로 들어가니 직접 골라 주세요.
