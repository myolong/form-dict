일기 양식 — 줄 노트 일기장, 바로 인쇄

날짜, 날씨, 기분을 고르고 오늘 있었던 일을 적으면 줄 노트 모양의 A4 일기장이 완성됩니다. 빈 양식으로 여러 장 인쇄해 손으로 써도 좋아요.

일기 양식 쓰는 법

  1. 날짜·날씨·기분을 고르면 위쪽 칸에 들어갑니다.
  2. 오늘 있었던 일을 적으면 줄 노트 위에 글이 들어갑니다. 내용이 짧으면 남는 줄은 손으로 더 써도 됩니다.
  3. 감사한 일 3가지는 작은 것이라도 좋습니다. 매일 쓰면 기분이 가라앉은 날에도 하루를 정리하는 데 도움이 됩니다.
  4. 손으로 쓰고 싶으면 빈 양식 인쇄를 눌러 여러 장 뽑아 두세요.

입력 내용은 서버로 보내지 않고 이 브라우저에만 저장됩니다.

자주 묻는 질문

일기는 어떻게 쓰면 꾸준히 쓸 수 있나요?

길게 쓰려고 하기보다 하루 서너 줄, 감사한 일 3가지만 적어도 충분합니다. 같은 시간에 쓰는 습관을 들이면 오래 갑니다.

손으로 쓰려면 어떻게 하나요?

'빈 양식 인쇄'를 누르면 날짜·날씨만 비운 줄 노트가 인쇄됩니다. 여러 장 인쇄해 묶어 쓰면 일기장이 됩니다.

입력한 일기가 다른 사람에게 보이나요?

아니요. 입력 내용은 서버로 보내지 않고 이 브라우저에만 저장됩니다. 공용 컴퓨터라면 다 쓴 뒤 '입력 지우기'를 누르세요.
