회사·인사 서류

  • 사직서퇴사할 때 내는 기본 양식. 사유·퇴직일만 채우면 완성
  • 재직증명서은행·관공서 제출용. 회사 담당자가 발급할 때 쓰는 양식
  • 경력증명서퇴사한 회사에서 받는 근무 경력 증명 양식
  • 시말서업무상 실수·잘못에 대한 경위와 재발 방지를 적는 양식
  • 경위서사고·문제가 생긴 경위를 사실대로 설명하는 양식

차용증·위임장·각서

  • 차용증돈을 빌리고 빌려줄 때. 한글 금액·분할 상환표 자동
  • 위임장다른 사람에게 서류 발급·업무 처리를 맡길 때
  • 인감증명서 위임장인감증명서 대리 발급용 법정 서식 (빈 서식 인쇄)
  • 각서약속한 내용을 문서로 남길 때

견적·거래 서류

  • 견적서품목·수량·단가만 넣으면 합계·부가세·한글 금액 자동
  • 거래명세서물건·서비스를 넘길 때 함께 주는 명세. 합계 자동
  • 간이영수증돈을 받았다는 확인증. 합계·한글 금액 자동

결재·보고 서류

  • 지출결의서회사 돈을 쓰기 전·후 결재받는 양식. 결재란 칸 수 선택
