이렇게 쓰세요

  1. 내역 파일 받기 — 카드사나 은행 홈페이지·앱에서 이용내역(거래내역)을 조회한 뒤 '엑셀 다운로드'로 저장합니다. 한 달 단위로 받으면 보기 편해요.
  2. 파일 넣기 — 위 칸에 끌어다 놓거나 눌러서 고릅니다.
  3. 열 확인 — 날짜·사용처·금액 열을 자동으로 골라 두니 미리보기 표에서 맞는지만 확인합니다. 통장 내역은 '통장(출금·입금 따로)'을 고르세요.
  4. 분류 고치기 — 자동 분류가 틀린 거래만 바꿉니다. 같은 가게는 한 번만 바꾸면 됩니다.
  5. 인쇄·저장 — A4 가계부로 인쇄하거나 PDF로 저장하고, 엑셀로 저장해 두면 다음 달 파일과 이어 붙여 볼 수 있어요.

분류 기준

가게 이름에 들어간 단어로 나눕니다. 예를 들어 '커피·카페·베이커리'는 카페·간식, '마트·정육'은 장보기, '택시·주유·주차'는 교통·차량, '관리비·전기·가스'는 주거·공과금으로 들어갑니다. 이름만으로 알 수 없는 가게는 기타로 들어가니 직접 골라 주세요.

개인정보 걱정 없이

  • 파일은 브라우저 안에서만 열고 계산합니다. 서버로 보내지 않고 저장하지도 않습니다.
  • 기억하는 것은 내가 직접 바꾼 '사용처 → 분류' 짝뿐이며, 이것도 이 브라우저에만 남습니다. [기억 지우기]로 언제든 지울 수 있어요.
  • 공용 PC에서 썼다면 다운로드 폴더의 내역 파일을 지워 주세요.

자주 묻는 질문

파일이 서버로 올라가지 않나요?

올라가지 않습니다. 파일은 지금 보고 있는 브라우저 안에서만 읽고 계산하며, 이 사이트 서버에는 파일을 받는 기능 자체가 없습니다. 페이지가 열린 뒤 인터넷을 끊어도 그대로 작동하는 것으로 확인할 수 있어요.

어떤 파일을 넣을 수 있나요?

카드사·은행 홈페이지나 앱의 이용내역(거래내역) 조회 화면에서 '엑셀 다운로드'나 '저장'으로 받은 .xlsx, .xls, .csv 파일입니다. PDF와 비밀번호가 걸린 파일은 아직 읽지 못합니다.

파일마다 칸 이름이 다른데 괜찮나요?

'이용일자·거래일시', '가맹점명·적요', '이용금액·출금' 같은 이름을 보고 자동으로 골라 둡니다. 틀린 경우 2단계에서 날짜·사용처·금액 열을 직접 고르면 됩니다.

분류가 틀리게 나와요.

거래 내역 표에서 분류를 바로 바꾸면 같은 사용처가 모두 함께 바뀝니다. 바꾼 분류는 이 브라우저에 기억해 두었다가 다음에 파일을 넣을 때도 그대로 씁니다.

카드값이 통장에서 빠져나간 것도 지출로 잡히나요?

통장 내역의 카드대금 출금은 '이체·제외'로 분류해 합계에서 뺍니다. 카드 내역과 통장 내역을 각각 정리할 때 같은 돈이 두 번 잡히지 않게 하려는 것이에요. 자동으로 못 잡은 경우 분류를 '이체·제외'로 바꿔 주세요.

취소·환불은 어떻게 계산되나요?

카드 내역에서 금액이 마이너스(-)로 표시된 줄은 취소·환불로 보고 해당 분류 지출에서 뺍니다.

이 사이트의 양식과 설명은 일반적인 참고용입니다. 회사·기관·관공서에 정해진 양식이 있으면 그 양식을 우선 사용하고, 법률 문제는 전문가 상담을 받으세요. 입력한 내용은 서버로 전송·저장되지 않습니다.
