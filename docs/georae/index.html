거래명세서 양식 — 합계·부가세 자동 계산

공급자·공급받는자와 품목만 넣으면 공급가액·세액·합계가 자동 계산되는 거래명세서(거래명세표)가 완성됩니다.

입력 내용은 서버로 보내지 않고 이 브라우저에만 임시 저장됩니다.

거래명세서란?

물건이나 서비스를 넘길 때 무엇을 얼마나, 얼마에 주었는지 적어 주고받는 문서입니다. 거래명세표, 납품서라고도 부릅니다. 보통 2부를 만들어 공급자와 공급받는자가 1부씩 보관하고, 받는 쪽은 인수자 칸에 서명해 돌려줍니다.

견적서와 차이

  • 견적서: 거래 전에 "이 가격에 해 드릴 수 있다"고 알리는 문서
  • 거래명세서: 실제로 물건·서비스를 넘긴 뒤 내역을 확인하는 문서

쓰는 법

  1. 거래일과 공급자·공급받는자 정보를 적습니다.
  2. 품목, 규격, 수량, 단가를 넣으면 공급가액·세액·합계가 자동 계산됩니다.
  3. 지난 거래에서 남은 금액이 있으면 '전잔금'에 적습니다.
  4. 인쇄해서 2부를 만들고, 받는 쪽 확인 서명을 받아 둡니다.

거래명세서는 거래 내역을 확인하는 문서입니다. 회사의 회계 처리에 어떤 증빙이 필요한지는 거래처나 회사 담당자에게 확인하세요.

함께 많이 찾는 양식

  • 견적서품목·수량·단가만 넣으면 합계·부가세·한글 금액 자동
  • 간이영수증돈을 받았다는 확인증. 합계·한글 금액 자동
  • 지출결의서회사 돈을 쓰기 전·후 결재받는 양식. 결재란 칸 수 선택

이 사이트의 양식과 설명은 일반적인 참고용입니다. 회사·기관·관공서에 정해진 양식이 있으면 그 양식을 우선 사용하고, 법률 문제는 전문가 상담을 받으세요. 입력한 내용은 서버로 전송·저장되지 않습니다.
