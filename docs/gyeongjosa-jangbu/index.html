경조사 장부 — 받은 축의금·부의금 정리, 보낸 기록까지

결혼식·장례식에서 받은 축의금·부의금 명단을 정리하거나, 내가 다른 집에 낸 경조사비를 기록해 두세요. 인원과 합계가 자동으로 계산되고 A4로 인쇄됩니다.

작성 2026-11-16

입력 내용은 서버로 보내지 않고 이 브라우저에만 임시 저장됩니다.

경조사 장부 쓰는 법

  1. 장부 종류 고르기 — 우리 집 결혼식·장례식에서 받은 돈을 정리하면 '받은 내역', 다른 집에 낸 돈을 기록하면 '보낸 내역'을 고릅니다.
  2. 한 줄에 한 사람 — 받은 내역은 이름 / 관계 / 금액, 보낸 내역은 날짜 / 이름 / 행사 / 금액 순서로 적어요. 메모는 맨 뒤에 붙이면 됩니다.
  3. 합계 확인 — 맨 아래에 인원과 합계가 자동으로 나옵니다. 봉투 금액을 다 더한 값과 같은지 확인하세요.
  4. 인쇄·보관 — 명단이 길면 여러 장으로 이어서 인쇄되고, 표 제목 줄은 장마다 다시 나옵니다.

정리할 때 도움이 되는 팁

  • 관계 칸에 '신랑 회사', '신부 친구', '아버지 지인'처럼 누구 쪽 손님인지 적어 두면 감사 인사를 나눠 챙기기 쉬워요.
  • 화환·조화만 보낸 분, 계좌로 보낸 분도 메모 칸에 적어 두면 빠뜨리지 않습니다.
  • 보낸 내역을 꾸준히 적어 두면 나중에 상대 집 행사 때 참고가 됩니다.

자주 묻는 질문

방명록과 봉투 명단을 어떻게 옮기나요?

봉투를 하나씩 열면서 이름 / 관계 / 금액을 한 줄씩 적으면 번호·인원·합계가 자동으로 붙습니다. 엑셀에서 이름·관계·금액 열을 복사해 붙여 넣은 뒤 칸 사이를 / 로 바꿔도 됩니다.

답례 칸은 무엇인가요?

답례품이나 감사 인사를 챙긴 사람에게 체크하는 칸입니다. 인쇄해서 손으로 표시하세요.

보낸 경조사비도 기록할 수 있나요?

장부 종류에서 '보낸 내역'을 고르면 날짜·이름·행사·금액 순서의 기록장이 됩니다. 나중에 상대 집 행사 때 얼마를 받았는지, 보냈는지 확인할 때 쓰세요.

입력한 명단이 어디에 저장되나요?

서버로 보내지 않고 지금 쓰는 브라우저에만 임시 저장됩니다. 공용 PC라면 다 쓴 뒤 [입력 지우기]를 눌러 주세요.

함께 많이 찾는 양식

  • 아이 용돈기입장날짜·내용·금액만 적으면 남은 돈이 자동 계산. 빈 양식 인쇄도 가능
  • 월간 계획표 (달력)연월만 고르면 달력이 자동. 날짜별 일정 입력
  • 영수증 (돈 받은 확인)개인 간에 돈을 받았다는 확인증. 계약금·잔금·대여금 등
