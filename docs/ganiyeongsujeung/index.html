간이영수증 양식 — 칸 채우고 바로 인쇄

받는 분·품목·금액만 넣으면 합계와 한글 금액이 자동으로 들어간 간이영수증이 완성됩니다.

작성 2026-11-05 · 최종 수정 2026-11-07

개인 간에 계약금·잔금·빌려준 돈 등을 받았다는 확인증은 영수증(돈 받은 확인)을 쓰세요.

입력 내용은 서버로 보내지 않고 이 브라우저에만 임시 저장됩니다.

간이영수증 쓰는 법

  1. 받는 분: 돈을 낸 사람이나 회사 이름을 적습니다.
  2. 공급자: 돈을 받은 가게·사람의 상호, 사업자등록번호, 성명, 주소. 도장이나 서명을 꼭 받습니다.
  3. 품목: 무엇을 얼마에 샀는지 적으면 합계와 한글 금액이 자동으로 들어갑니다.
  4. 영수/청구: 이미 돈을 받았으면 '영수', 앞으로 받을 돈이면 '청구'를 고릅니다.

알아 두면 좋은 점

  • 금액은 숫자와 한글로 함께 적혀 있어야 고치기 어렵습니다.
  • 회사 경비로 처리하려는 경우, 간이영수증을 받아 줄지와 금액 한도는 회사마다 다릅니다. 경리 담당자에게 먼저 확인하세요.
  • 회사 안에서 비용을 청구할 때는 지출결의서에 영수증을 붙여 내는 경우가 많습니다.

자주 묻는 질문

'영수'와 '청구'는 어떻게 다른가요?

이미 돈을 받았으면 '영수', 앞으로 받을 돈이면 '청구'를 고릅니다.

간이영수증으로 회사 경비 처리가 되나요?

받아 주는지와 금액 한도는 회사마다 다릅니다. 경리 담당자에게 먼저 확인하세요.

공급자 도장은 꼭 받아야 하나요?

돈을 받은 사람의 도장이나 서명이 있어야 확인 문서가 되므로 꼭 받으세요.

함께 많이 찾는 양식

  • 견적서품목·수량·단가만 넣으면 합계·부가세·한글 금액 자동
  • 거래명세서물건·서비스를 넘길 때 함께 주는 명세. 합계 자동
  • 지출결의서회사 돈을 쓰기 전·후 결재받는 양식. 결재란 칸 수 선택
