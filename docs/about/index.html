사이트 소개

양식컨닝은 자주 쓰는 문서 양식을 회원가입이나 파일 다운로드 없이 브라우저에서 바로 작성할 수 있게 만든 무료 사이트입니다.

  • 칸을 채우면 오른쪽 A4 미리보기에 바로 반영됩니다.
  • [인쇄 · PDF 저장]을 누르면 A4 한 장으로 인쇄되고, 인쇄 창에서 'PDF로 저장'을 고르면 파일로 저장됩니다.
  • 견적서·거래명세서는 합계와 부가세, 한글 금액(일금 ○○원정)을 자동으로 계산합니다.
  • 입력한 내용은 서버로 전송되지 않고, 사용하는 브라우저에만 임시 저장됩니다.

양식과 작성법은 일반적인 참고용입니다. 회사·기관에 정해진 양식이 있으면 그 양식을 우선 사용해 주세요.
