용돈기입장 양식 — 남은 돈 자동 계산, 아이용 A4 인쇄

날짜·내용·금액을 한 줄씩 적으면 들어온 돈·쓴 돈·남은 돈이 자동으로 계산돼요. 아이가 손으로 쓰게 하려면 [빈 양식 인쇄]를 누르세요.

작성 2026-11-13

입력 내용은 서버로 보내지 않고 이 브라우저에만 임시 저장됩니다.

용돈기입장 쓰는 법

  1. 받은 날 바로 적기 — 용돈을 받으면 날짜와 함께 "+금액"으로 적습니다.
  2. 쓸 때마다 한 줄 — 무엇을 샀는지, 얼마였는지 적어요. 남은 돈은 자동으로 계산됩니다.
  3. 남은 돈 맞춰 보기 — 주말마다 지갑(저금통)의 돈과 '남은 돈'이 맞는지 확인해요. 다르면 빠진 기록을 찾아봅니다.
  4. 한 달 돌아보기 — 월말에 잘한 점·아쉬운 점·다음 달 다짐을 아이와 함께 적고, 부모님 확인 칸에 사인해 주세요.

이렇게 쓰면 더 좋아요

  • 이번 달 목표를 "○○원 모아서 ○○ 사기"처럼 구체적으로 정하면 기록할 이유가 생겨요.
  • 친척에게 받은 돈, 심부름 값도 빠짐없이 적게 해 주세요.
  • 다음 달 용돈기입장의 '지난달 남은 돈'에 이번 달 남은 돈을 옮겨 적으면 이어집니다.

자주 묻는 질문

받은 돈과 쓴 돈은 어떻게 구분하나요?

받은 돈은 금액 앞에 + 를 붙여 적으세요(예: 1 / 용돈 / +20000). + 가 없으면 쓴 돈으로 계산합니다.

아이가 직접 손으로 쓰게 하고 싶어요.

[빈 양식 인쇄]를 누르면 빈칸만 있는 용돈기입장이 인쇄됩니다. 이름과 목표만 적고 인쇄해도 남은 줄은 빈칸으로 나와요.

몇 살부터 쓰면 좋나요?

덧셈·뺄셈을 할 수 있는 초등학생 무렵부터 많이 씁니다. 처음에는 부모님이 함께 적고, 한 달에 한 번 돌아보기 칸을 같이 채워 보세요.

함께 많이 찾는 양식

  • 습관 체크표 (해빗 트래커)습관 최대 7개 × 한 달 날짜 칸. 연월 고르면 자동
  • 월간 계획표 (달력)연월만 고르면 달력이 자동. 날짜별 일정 입력
  • 오늘 할 일 (투두리스트)가장 중요한 3가지, 체크리스트, 시간표를 한 장에
